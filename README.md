## Text Analyzer — Лингвистический анализатор текста на русском языке

Анализатор текста для русского языка, ориентированный на извлечение **грамматических и прагматических признаков**:
- Повелительные глаголы (императивы)
- Имена собственные (люди)
- Типы вопросов (общие / специальные)

Результат возвращается в виде структурированного списка по предложениям с точными позициями (start, end) — подходит для дальнейшей разметки, визуализации или обучения моделей.
