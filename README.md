## Text Analyzer — Лингвистический анализатор текста на русском языке

Анализатор текста для русского языка, ориентированный на извлечение **грамматических и прагматических признаков**:
- Повелительные глаголы (императивы)
- Имена собственные (люди)
- Типы вопросов (общие / специальные)

Результат возвращается в виде структурированного списка по предложениям с точными позициями (start, end) — подходит для дальнейшей разметки, визуализации или обучения моделей.

## Запуск

0) Создание виртуального окружения

```shell
py -m venv .env
.env\Scripts\activate
```

1) Установка зависимостей

```shell
poetry install
```

2) Запуск API

```shell
 cd .\src\api\
```

```shell
poetry run uvicorn app:app
```

API будет доступно по адресу: http://127.0.0.1:8000

Swagger UI: http://127.0.0.1:8000/docs

Эндпоинты API:
1) GET/ — Welcome endpoint (возвращает {"message": "Speech Analyzer API"})
2) POST/analyze — text analyzing (возвращает результаты анализа текста: найденные императивы, имена собственные и вопросы с указанием их типа)
